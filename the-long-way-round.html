THE LONG WAY ROUND

Role : Game Programmer | Genre : Idle / Clicker | Platform : Mobile | Engine : Unity

GAME SUMMARY

The Long Way Round is an idle clicker told through sound. You start as a lone musician under a streetlamp on a rainy corner, and every tap is a strum that earns Vibes. Vibes hire collaborators, buy gear and compose lyric fragments, and each purchase adds a real part to the music, until a single acoustic guitar becomes a full band.

// Every song is data: its lyric fragments, costs and effects.
// Adding content means adding entries, not writing new systems.
static void BuildSongbook(ContentDatabase db)
{
    void Song(string id, string title, int act, string stem, Effect bonus, Condition unlock,
              (string line, double cost, Effect eff)[] lines)
    {
        db.songs.Add(new SongDef { id = id, title = title, act = act,
                                   stemId = stem, completionBonus = bonus, unlock = unlock });
        for (int i = 0; i < lines.Length; i++)
        {
            db.lyrics.Add(new LyricDef
            {
                id = id + "_l" + i,
                songId = id,
                line = lines[i].line,
                cost = lines[i].cost,
                effect = lines[i].eff,
                order = i
            });
        }
    }

    // Completing a song unlocks a new audio stem in the live mix.
    Song("song1", "Rain On The Awning", 1, "guitar_body", Glob(1.5), None(), new[]
    {
        ("counting cars instead of sheep", 180d, TapAdd(3)),
        ("finding joy in sorrow", 900d, Glob(1.2)),
        ("a paper cup of applause", 3.4e3, CrewM("hat", 2)),
        ("the streetlight hums in B flat", 9.5e3, Tap(2)),
        ("every drop keeps time for me", 2.6e4, Glob(1.3)),
    });
}

CODE ARCHITECTURE

  • Procedural Audio Engine: The soundtrack has no audio files. A live synthesiser and sequencer generate it at runtime, so the tempo lifts while the player taps and settles when they stop.
  • Stem-Based Progression: Every collaborator, gear upgrade and gig unlocks a new audio stem. Progress is heard, not just counted: hire a cellist and a cello joins the arrangement.
  • Data-Driven Content Database: Acts, collaborators, upgrades, songs and lyric fragments are data built from reusable Effect and Condition definitions: 7 acts, 16 collaborators, ~45 upgrades and 50 lyric fragments, with no new code needed for new content.
  • Tap Intensity Model: A fast-attack, slow-release average of player input drives both the music's tempo and the pace of progression.
  • One-Click Builder: A single editor command generates the folders, pixel-art sprites, content database, UI theme, parallax scene and Android player settings, and is safe to re-run.
