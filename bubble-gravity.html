Game Summary

Bubble Gravity is a bubble shooter set in an alchemist's workshop, built around one new idea: gravity zones that pull every shot left, right, up or down. Players bank shots through the zones to match colours, collect gems and clear the board, with five power-ups and 30 levels that ramp from tutorial to expert.

Bubble Gravity

Code Architecture

  • One Shared Physics Simulation: The real shot, the curved aim line, the Aim Hint power-up and the balancing bot all run the same gravity-zone simulation, so the aim preview always matches what the shot actually does.
  • Bot-Driven Balancing: A bot plays every level 30+ times, reports a win rate, and automatically sets the shot count and star score thresholds. The 30 levels ramp from about a 97% bot win rate down to 53%.
  • Pluggable Power-Ups: Each power-up is a ScriptableObject asset. New effects implement an IPowerUpEffectHandler interface and appear in the shop and in-level tray automatically.
  • Custom Level Editor: An editor window with colour brushes, flood fill, mirroring, gravity-zone editing, live test shots and batch generation across 12 shapes, 6 colouring styles and 11 zone presets.
  • SDK-Safe Builds: Scripting defines detect LevelPlay ads, Cloud Save and Google Play Games. Without them, ads are simulated and saves stay offline, so the project always compiles.
  • Tested Core Rules: The matching and dropping rules are covered by 20 unit tests, and all scripts compile cleanly with SDKs on, off, and alongside the editor tools.
