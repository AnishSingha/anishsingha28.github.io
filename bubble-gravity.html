BUBBLE GRAVITY

Role : Game Programmer | Genre : Puzzle / Bubble Shooter | Platform : Mobile | Engine : Unity

GAME SUMMARY

Bubble Gravity is a bubble shooter set in an alchemist's workshop, built around one new idea: gravity zones that pull every shot left, right, up or down. Players bank shots through the zones to match colours, collect gems and clear the board, with five power-ups and 30 levels that ramp from tutorial to expert.

public enum PowerUpEffectType
{
    Undefined,
    AimHint,        // shows the best shot + the FULL bending path
    Bomb,           // loads a bomb bubble that clears everything around its impact
    Rainbow,        // loads a rainbow bubble that matches every colour it touches
    ExtraShots,     // +effectValue shots immediately
    AntiGravity     // gravity zones are switched off for the next shot
}

// One asset per power-up. Duplicate one, give it a new id + effect
// and it appears in the Shop and the in-level tray automatically.
[CreateAssetMenu(fileName = "PowerUp_", menuName = "Bubble Gravity/Power-Up Definition")]
public class PowerUpDefinition : ScriptableObject
{
    [Tooltip("Stable unique id used for save data and lookups.")]
    public string powerUpId;
    public string displayName;
    [TextArea] public string description;
    public Sprite icon;

    [Header("Economy")]
    public int coinCost = 100;
    public int startingAmount = 1;

    [Header("Availability")]
    public bool availableInLevel = true;
    public bool availableInShop = true;
    public bool showInTray = true;
    public int unlockLevel = 1;

    [Header("Effect")]
    public PowerUpEffectType effectType = PowerUpEffectType.Undefined;
    public float effectValue;
}

// Implement on a MonoBehaviour to add a new power-up effect.
public interface IPowerUpEffectHandler
{
    PowerUpEffectType EffectType { get; }
}

CODE ARCHITECTURE

  • One Shared Physics Simulation: The real shot, the curved aim line, the Aim Hint power-up and the balancing bot all run the same gravity-zone simulation, so the aim preview always matches the actual shot.
  • Bot-Driven Balancing: A bot plays every level 30+ times, reports a win rate and automatically sets shot counts and star thresholds. The 30 levels ramp from about 97% bot win rate down to 53%.
  • Pluggable Power-Ups: Each power-up is a ScriptableObject asset. New effects implement IPowerUpEffectHandler and appear in the shop and in-level tray automatically.
  • Custom Level Editor: Colour brushes, flood fill, mirroring, gravity-zone editing, live test shots and batch generation across 12 shapes, 6 colouring styles and 11 zone presets.
  • SDK-Safe Builds: Scripting defines detect LevelPlay, Cloud Save and Google Play Games. Without them, ads are simulated and saves stay offline, so the project always compiles.
