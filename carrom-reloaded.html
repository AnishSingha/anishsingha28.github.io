Game Summary

Carrom Reloaded is a game made within 2 days for the event BYOG 2025 on the topic RE:{THINK, MIX, MAKE}. In this game instead of using striker, we drag and launch the board to move the pieces around and secure the carrom coins.

Carrom Reloaded

Code Architecture

  • Single Responsibility Principle: The EndTurnSequence no longer tries to calculate how the rules work; it just asks EvaluateTurnRules() what happens next and routes the game state accordingly. This is much easier to read and debug.
  • Self-Documenting Code: By creating boolean methods like HasValidCoverPiece() and ResolveQueenCoverAttempt(), the code reads like plain English. A recruiter or lead programmer does not need to decipher nested if/else statements to understand the flow.
  • Scalable Architecture: Adding a new game mode (like a time-attack mode) or tweaking the rules based on playtesting feedback only requires modifying the isolated rule-checking methods rather than tearing apart the entire sequence coroutine.
  • Modular Edge-Case Handling: The logic handles the specific edge case of pocketing the Queen and a cover piece in the exact same shot without duplicating code, relying strictly on the HasValidCoverPiece() check.
