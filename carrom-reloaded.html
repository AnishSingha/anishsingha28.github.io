CARROM RELOADED

Role : Game Programmer | Genre : Casual | Platform : PC/Mobile | Time : 2 Days | Engine : Unity 6

GAME SUMMARY

Carrom Reloaded is a game made within 2 days for the event BYOG 2025 on the topic RE:{THINK, MIX, MAKE}. In this game instead of using striker, we drag and launch the board to move the pieces around and secure the carrom coins.

private IEnumerator EndTurnSequence()
{
    yield return StartCoroutine(RecenterCameraCoroutine(boardRigidbody.position));

    bool earnsAnotherTurn = EvaluateTurnRules();

    if (currentMode == GameMode.LevelBased && !earnsAnotherTurn)
    {
        CheckLevelEndConditions();
    }
    else if (currentMode == GameMode.PVP)
    {
        if (CheckPVPWinConditions()) yield break;

        if (earnsAnotherTurn) EnterAimingState();
        else SwitchTurn();
    }
    else
    {
        EnterAimingState();
    }
}

private bool EvaluateTurnRules()
{
    if (isAwaitingQueenCover) return ResolveQueenCoverAttempt();
    if (queenPocketedThisTurn) return HandleQueenPocketed();

    return currentMode == GameMode.PVP ? pocketedOwnPieceThisTurn : false;
}

private bool HandleQueenPocketed()
{
    isAwaitingQueenCover = true;
    if (currentMode == GameMode.PVP) queenPocketedBy = currentPlayer;

    if (HasValidCoverPiece())
    {
        ConfirmQueenCovered();
        return true;
    }

    return true;
}

private bool ResolveQueenCoverAttempt()
{
    bool isCurrentPlayersCoverAttempt = (currentMode == GameMode.LevelBased) ||
                                        (currentMode == GameMode.PVP && currentPlayer == queenPocketedBy);

    if (!isCurrentPlayersCoverAttempt) return false;

    if (HasValidCoverPiece())
    {
        ConfirmQueenCovered();
        return true;
    }

    isAwaitingQueenCover = false;
    StartCoroutine(ResetQueenCoroutine());
    return false;
}

private bool HasValidCoverPiece()
{
    return (currentMode == GameMode.LevelBased && pocketedAnyPieceThisTurn) ||
           (currentMode == GameMode.PVP && pocketedOwnPieceThisTurn);
}

private void ConfirmQueenCovered()
{
    queenIsCovered = true;
    isAwaitingQueenCover = false;

    if (currentMode == GameMode.PVP)
    {
        if (queenPocketedBy == PlayerTurn.White) whiteScore += 2;
        else blackScore += 2;
    }
}

CODE ARCHITECTURE

  • Single Responsibility Principle: The EndTurnSequence no longer tries to calculate how the rules work; it just asks EvaluateTurnRules() what happens next and routes the game state accordingly. This is much easier to read and debug.
  • Self-Documenting Code: By creating boolean methods like HasValidCoverPiece() and ResolveQueenCoverAttempt(), the code reads like plain English. A recruiter or lead programmer does not need to decipher nested if/else statements to understand the flow.
  • Scalable Architecture: If you decide to add a new game mode (like a time-attack mode) or tweak the rules based on future playtesting feedback, you only have to modify the isolated rule-checking methods rather than tearing apart the entire sequence coroutine.
  • Modular Edge-Case Handling: The logic elegantly handles the specific edge case of "pocketing the Queen and a cover piece in the exact same shot" without duplicating code, relying strictly on the HasValidCoverPiece() check.
