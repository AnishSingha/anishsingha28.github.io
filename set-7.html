Game Summary

Set-7 is a sequence-building roguelike where the deck is your life. Players must manage a 52-card resource to hit a self-imposed target. The game centers on a high-stakes decision at the end of every successful round: Secure the profit or risk it all for a higher multiplier.

Code Architecture

  • Data-Driven Design: Using enums and configurable data instead of hardcoded logic allows for rapid prototyping and balancing without rewriting the core game loop.
  • Decoupled Architecture: Separating math and rules from UI and animations allows systems to calculate instantly in the background (perfect for predictive UI) without being slowed down by visual timings.
  • Asynchronous State Management: Locking inputs during distinct execution phases prevents game-breaking bugs, like double-clicks or race conditions, ensuring a stable flow.
  • Optimized Data Structures: Utilizing efficient structures (like O(1) HashSets) for rule validation guarantees maximum performance and prevents frame drops as complexity scales.
  • Failsafe Execution: Implementing early-exit conditions for invalid player actions immediately and safely resets the game state, saving processing power and preventing cascading errors.
