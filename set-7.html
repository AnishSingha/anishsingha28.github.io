SET-7

Role : Game Programmer | Genre : Casual | Platform : Mobile | Time : 3 months | Engine : Unity 6

GAME SUMMARY

Set-7 is a sequence-building roguelike where the deck is your life. Players must manage a 52-card resource to hit a self-imposed target. The game centers on a high-stakes decision at the end of every successful round: Secure the profit or risk it all for a higher multiplier.

private IEnumerator CheckInSequence(List<Card> cardsInPlay)
{
    // 1. Lock State
    isCheckingIn = true;
    checkInButton.interactable = false;
    ToggleCardInteraction(cardsInPlay, false);

    // 2. Progressive Validation Phase
    if (bustOnCheckInOnly)
    {
        Card invalidCard = ValidateSetRules(cardsInPlay);
        if (invalidCard != null)
        {
            ResetSafeScoreUI();
            yield return StartCoroutine(AnimateBustSequence(invalidCard));

            ResolveBustState();
            yield break; // Halt execution on invalid play
        }
    }

    // 3. Scoring & Presentation Phase
    int baseScoreAccumulated = 0;

    foreach (Card card in cardsInPlay)
    {
        int finalCardScore = CalculateSingleCardScore(card, activePowerCards);
        baseScoreAccumulated += finalCardScore;

        yield return StartCoroutine(AnimateCardScorePopup(card, finalCardScore));
    }

    // 4. Global Modifiers Application
    int finalTotalScore = ApplyGlobalSetMultipliers(baseScoreAccumulated, cardsInPlay);

    // 5. Game State Resolution
    CurrencyManager.instance.AddInGameCurrency(finalTotalScore, cardsInPlay.Count);
    UpdateFinalScoreUI(finalTotalScore);

    if (cardsInPlay.Count == 7) RefillDiscards();
    else GainDiscard();

    // 6. Cleanup & Next State Trigger
    yield return new WaitForSeconds(cardClearDelay);
    yield return StartCoroutine(AnimateClearFinalSlots());

    isCheckingIn = false;
    EvaluateBetTarget(finalTotalScore);
}

// Extracted Validation Logic for clean reads
private Card ValidateSetRules(List<Card> cardsInPlay)
{
    HashSet<int> seenRanks = new HashSet<int>();
    Card lastValidCard = null;
    int lastValidIndex = -1;

    for (int i = 0; i < cardsInPlay.Count; i++)
    {
        Card currentCard = cardsInPlay[i];

        // A. Duplicate Check
        if (!currentCard.isJoker && !seenRanks.Add(currentCard.cardRank))
            return currentCard;

        // B. Sequence Check
        if (lastValidCard != null)
        {
            int distance = i - lastValidIndex;
            if (!IsRankDistanceValid(lastValidCard.cardRank, currentCard.cardRank, distance))
                return currentCard;
        }

        lastValidCard = currentCard;
        lastValidIndex = i;
    }
    return null; // Passes all checks
}

CODE ARCHITECTURE

  • Data-Driven Design: Using enums and configurable data instead of hardcoded logic allows for rapid prototyping and balancing without rewriting the core game loop.
  • Decoupled Architecture: Separating math and rules from UI and animations allows systems to calculate instantly in the background (perfect for predictive UI) without being slowed down by visual timings.
  • Asynchronous State Management: Locking inputs during distinct execution phases prevents game-breaking bugs, like double-clicks or race conditions, ensuring a stable flow.
  • Optimized Data Structures: Utilizing efficient structures (like O(1) HashSets) for rule validation guarantees maximum performance and prevents frame drops as complexity scales.
  • Failsafe Execution: Implementing early-exit conditions for invalid player actions immediately and safely resets the game state, saving processing power and preventing cascading errors.
