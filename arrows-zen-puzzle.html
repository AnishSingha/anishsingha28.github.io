ARROWS: ZEN PUZZLE

Role : Game Programmer | Genre : Puzzle | Platform : Mobile | Engine : Unity

GAME SUMMARY

Arrows: Zen Puzzle is a meditative puzzle game where players navigate intricate, shifting grids by carefully orchestrating the movement of arrows. Every move plays a note tuned to the backing track, so solving a level builds into a melody. Released on Google Play.

public enum ArrowPattern { Random, Spiral, Wave }

// -----------------------------------------------------------------
// Fills whatever a pattern didn't cover (e.g. Spiral's layer limit)
// so the rest still gets a proper, solvable layout.
// Safe by construction: this region's arrows are only ever appended
// AFTER the pattern's own arrows, so by the time any of these need
// to escape, everything the pattern covered is already gone - the
// random carve only has to worry about cells within this region.
// -----------------------------------------------------------------
private List<SavedArrow> FillRemainderRandom(HashSet<Vector2Int> region)
{
    if (region.Count == 0) return new List<SavedArrow>();

    int minTail = GetMinTailLength(levelDifficulty);
    int maxTail = overrideMaxArrowLength
        ? Mathf.Max(minTail, customMaxArrowLength)
        : GetMaxTailLength(levelDifficulty);
    float turnChance = GetTurnChance(levelDifficulty);

    List<SavedArrow> best = null;
    int bestScore = int.MinValue;
    var sw = System.Diagnostics.Stopwatch.StartNew();
    int tries = 0, good = 0;

    // Carve candidates within a fixed attempt + time budget,
    // keep the hardest board instead of searching forever.
    while (good < candidateBoards && tries < maxCarveAttempts
           && sw.Elapsed.TotalSeconds < timeBudgetSeconds)
    {
        tries++;
        var arrows = CarveSolvableBoard(region, maxTail, turnChance);
        if (arrows == null) continue;
        good++;
        int score = ScoreBoardDifficultyFast(arrows, out _, out _);
        if (score > bestScore) { bestScore = score; best = arrows; }
    }
    return best;
}

CODE ARCHITECTURE

  • Solvable by Construction: Levels are carved so every arrow has a guaranteed escape order the moment it is placed. Solvability is built in rather than checked afterwards with an expensive search.
  • Time-Budgeted Generation: The generator carves several candidate boards within a fixed attempt and time budget, scores each for difficulty and keeps the hardest. 30x30 boards that used to freeze the editor for 30+ minutes now generate reliably.
  • Extensible Pattern System: Random, Spiral and Wave layouts share one pipeline. A new pattern needs one enum case and one method, and it inherits the solvability guarantee automatically.
  • Difficulty Without Shortcuts: Every arrow keeps at least one body segment and the generator rewards inward and outward turns, so levels stay hard instead of collapsing into arrows that all point the same way.
  • Regression-Tested Tooling: Generator changes were verified against a 160-case regression suite, including extreme aspect ratios like 50x4 and 4x50 boards.
