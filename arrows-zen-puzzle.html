Game Summary

Arrows: Zen Puzzle is a meditative puzzle game where players navigate intricate, shifting grids by carefully orchestrating the movement of arrows. Every move plays a note tuned to the backing track, so solving a level builds into a melody. Released on Google Play.

Arrows: Zen Puzzle

Code Architecture

  • Solvable by Construction: Levels are carved so that every arrow has a guaranteed escape order at the moment it is placed. Solvability is built in rather than checked afterwards with an expensive search.
  • Time-Budgeted Generation: The generator carves several candidate boards within a fixed attempt and time budget, scores each one for difficulty and keeps the hardest. Large 30x30 boards that used to freeze the editor for 30+ minutes now generate reliably.
  • Difficulty Without Shortcuts: Every arrow keeps at least one body segment and the generator rewards inward and outward turns, so levels stay hard instead of collapsing into arrows that all point the same way.
  • Extensible Pattern System: Random, Spiral and Wave layouts share one pipeline: plan lengths, slice into segments, finalize. A new pattern needs one enum case and one method, and it inherits the solvability guarantee automatically.
  • Configurable Arrow Sizing: A shared length planner sizes arrows along a Fibonacci curve or fixed lengths, with overrides such as a maximum length for the random arrows inside a Spiral's outer layers.
  • Regression-Tested Tooling: Generator changes were verified against a 160-case regression suite, including extreme aspect ratios like 50x4 and 4x50 boards.
